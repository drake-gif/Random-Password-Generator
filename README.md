Random-Password-Generator

The Random-Password-Generator project was built using plain HTML, CSS & Js (Javascript) codes. Nothing more nothing less.

index.html
    The page structure: the password box, the eye button, the Copy button, the options and the Generate button to generate the actual password
style.css
    The styling, including simple colours for viewing
script.js
   * The logic that builds the password using [ crypto.getRandomValues() ], a secure random function built into the browser.

App Features

> Length from 8 to 64 characters
> Lowercase, uppercase, numbers and symbols
> Option to skip look-alike characters (`O`, `0`, `l`, `I`, `1`)
> Strength meter
> Eye button to show and hide the password
> Copy button for copying generated password
> Welcome message that disappears on its own

How to run Random-Pawword-Generator

After cloning this project to your laptop 
Open `index.html` in your browser, or right-click it in VS Code and choose Open with Live Server.
